# Кодолесье

Учебная RPG на русском языке для первого знакомства с Python. 18 квестов, 6 глав. Герой ходит по лесным тропам, собирает кристаллы и побеждает теневых стражей, исполняя программу ученика.

## Как запустить на этом Mac

1. Откройте файл **Запустить игру.command** двойным щелчком.
2. Игра откроется в браузере по адресу http://127.0.0.1:8765.
3. Оставьте окно запуска открытым, пока играете. Для остановки нажмите в нём Control+C.

На компьютере уже установлен Python 3. Дополнительные библиотеки и интернет не нужны. Если macOS предлагает выбрать приложение для `.command`, откройте файл через Terminal. Альтернативный запуск из Terminal: перейдите в папку Education и выполните `python3 -B server.py`, затем откройте указанный адрес. Открывать `index.html` напрямую не нужно: Python запускается локальным сервером.

## Как играть

Читайте задачу, дописывайте программу и нажимайте **Запустить код** или Command+Enter. На Windows/Linux работает Ctrl+Enter. Карта показывает движение героя, журнал — действия с номерами строк и ошибки, под журналом видны значения переменных во время действий. Направления вверх/вниз/влево/вправо соответствуют экрану. Каждый запуск начинает уровень с исходной позиции.

После `hero.` появляется список доступных команд с описаниями. Продолжайте вводить название, чтобы отфильтровать список. Стрелки ↑/↓ выбирают команду, Enter или Tab вставляют её, Esc закрывает подсказки. Можно выбрать команду мышью; Ctrl+Space повторно вызывает список. Для команд с обязательным аргументом вставляется выделенный пример, который можно сразу заменить. В строках и комментариях подсказки не появляются.

Когда список подсказок закрыт, Tab вставляет четыре пробела, Enter сохраняет отступ и добавляет его после двоеточия. Кнопка с солнцем последовательно открывает две подсказки. Справочник доступен в любой момент. Скорость анимации переключается между 1×, 2× и 4×. Кнопка со стрелкой возвращает начальный код после подтверждения.

Для победы нужно дойти до портала, собрать все кристаллы, победить всех стражей и использовать конструкцию Python текущего урока. Новые квесты открываются последовательно. XP начисляется только один раз за квест. Ограничения на число попыток нет.

## План занятий

| Занятие | Квесты | Основные темы |
|---|---|---|
| 1 | 1–3 | Команды, последовательность, комментарии, вызовы методов |
| 2 | 4–6 | Переменные, арифметика, строки |
| 3 | 7–9 | for, range, тело цикла, вложенные циклы |
| 4 | 10–12 | True/False, if, else, проверки в цикле |
| 5 | 13–15 | while, отрицание not, функции и параметры |
| 6 | 16–18 | return, списки, самостоятельный итоговый алгоритм |

Ориентир: 30–45 минут на занятие; подстраивайтесь под темп ученика. В начале попросите предсказать, куда пойдёт герой. После запуска обсудите разницу между прогнозом и результатом. Ошибка — повод прочитать журнал и изменить одну часть программы. В конце попросите объяснить решение своими словами и придумать его вариант.

Кнопка шестерёнки открывает раздел наставника со статистикой, возможностью открыть все уровни и экспортом прогресса. Эталонные решения доступны преподавателю в **solutions.py**. Не показывайте их до самостоятельной попытки. Проверка темы подтверждает наличие изучаемых конструкций в коде; понимание и осмысленность их использования лучше проверить устным объяснением.

## Сохранение

Решения, пройденные квесты и число попыток сохраняются автоматически в localStorage браузера для адреса игры. Используйте тот же браузер и адрес. Приватный режим или очистка данных могут удалить прогресс. В разделе наставника можно скачать JSON с прогрессом и текстами решений для архива; автоматического импорта в этой версии нет. Несколько учеников могут использовать отдельные профили браузера.

## Выполнение Python

Программы исполняются настоящим локальным Python 3 в отдельном процессе. Для уроков доступны команды героя, переменные, числа, строки, списки, условия, циклы, функции, return и простые встроенные функции: range, len, int, str, bool, abs, min, max, print. Импорты, файловые операции, доступ к внутренним объектам Python и внешние библиотеки не предоставляются. Ограничены время выполнения, размеры строк и списков, рост чисел и число игровых действий. На Linux дополнительно установлен лимит адресного пространства процесса; macOS не поддерживает этот лимит тем же способом. Сервер доступен только с этого компьютера. Это локальная учебная среда, а не сервер для публикации в интернете.

Игра полностью автономна: графика рисуется средствами браузера, внешних шрифтов, картинок, аналитики и сетевых зависимостей нет. Название, графика и сюжет самостоятельные; CodeCombat послужил ориентиром для механики обучения.

## Файлы

- `server.py` — локальный сервер и запуск программ в отдельном процессе.
- `engine.py` — правила мира и проверка Python.
- `levels.py` — тексты, карты и темы 18 квестов.
- `solutions.py` — решения для наставника.
- `index.html`, `style.css`, `app.js` — интерфейс, редактор и рисованная карта.
- `test_game.py` — проверка кампании и обработки ошибок.

Проверка: `python3 -B -m unittest -v test_game.py`.

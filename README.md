# Кодолесье

Учебная RPG на русском языке для первого знакомства с Python. 36 квестов, 7 глав. Герой ходит по лесным тропам, собирает кристаллы и побеждает теневых стражей, исполняя программу ученика.

## Как теперь работает игра

Игра полностью выполняется в браузере. Интерфейс работает на HTML, CSS и JavaScript, а настоящий Python запускается через Pyodide (Python, собранный в WebAssembly). Серверная программа не нужна: проект можно разместить на GitHub Pages.

Python работает в отдельном Web Worker, поэтому выполнение программы ученика не блокирует анимацию и кнопки. При слишком долгом выполнении среда автоматически перезапускается.

После публикации все компоненты, включая Pyodide, загружаются с самого сайта: внешних CDN-зависимостей нет. Саму страницу нельзя надёжно проверять двойным щелчком по `index.html`, потому что браузеры ограничивают загрузку Worker и Python-файлов с `file://`.

## Локальная проверка

В Terminal перейдите в папку проекта и запустите обычный статический сервер:

```bash
python3 -m http.server 8765
```

После этого откройте http://127.0.0.1:8765. Этот Python-процесс только раздаёт файлы для локальной проверки; программы ученика всё равно исполняются внутри браузера.

## Публикация на GitHub Pages

1. Создайте на GitHub новый репозиторий, например `kodolesye`.
2. В Terminal перейдите в эту папку `Education`.
3. Выполните команды из раздела «Команды для первой публикации» ниже.
4. На странице репозитория откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**.
6. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
7. Через несколько минут игра появится по адресу `https://ИМЯ.github.io/kodolesye/`.

### Команды для первой публикации

Замените `ИМЯ` на имя своего аккаунта GitHub:

```bash
git init
git add .
git commit -m "Publish Kodolesye browser game"
git branch -M main
git remote add origin https://github.com/ИМЯ/kodolesye.git
git push -u origin main
```

Файл `.gitignore` исключает локальный сервер, тесты и эталонные решения. Они останутся на компьютере, но не попадут в публичный репозиторий.

## Как играть

Читайте задачу, дописывайте программу и нажимайте **Запустить код** или Command+Enter. На Windows/Linux работает Ctrl+Enter. Карта показывает движение героя, журнал — действия с номерами строк и ошибки, под журналом видны значения переменных во время действий. Направления вверх/вниз/влево/вправо соответствуют экрану. Каждый запуск начинает уровень с исходной позиции.

После `hero.` появляется список доступных команд с описаниями. Продолжайте вводить название, чтобы отфильтровать список. Стрелки ↑/↓ выбирают команду, Enter или Tab вставляют её, Esc закрывает подсказки. Можно выбрать команду мышью; Ctrl+Space повторно вызывает список. Для команд с обязательным аргументом вставляется выделенный пример, который можно сразу заменить. В строках и комментариях подсказки не появляются.

Когда список подсказок закрыт, Tab вставляет четыре пробела, Enter сохраняет отступ и добавляет его после двоеточия. Кнопка с солнцем последовательно открывает две подсказки. Справочник доступен в любой момент. Скорость анимации переключается между 1×, 2× и 4×. Кнопка со стрелкой возвращает начальный код после подтверждения.

Для победы нужно дойти до портала, собрать все кристаллы, победить всех стражей и использовать конструкцию Python текущего урока. Новые квесты открываются последовательно. XP начисляется только один раз за квест. Ограничения на число попыток нет.

## План занятий

| Занятие | Квесты | Основные темы |
|---|---|---|
| 1 | 1–3 | Команды, последовательность, комментарии, вызовы методов |
| 2 | 4–6 | Переменные, арифметика, строки |
| 3 | 7–9 | for, range, тело цикла, вложенные циклы |
| 4 | 10–12 | True/False, if, else, проверки в цикле |
| 5 | 13–15 | while, отрицание not, функции и параметры |
| 6 | 16–18 | return, списки, самостоятельный итоговый алгоритм |
| 7 | 19–21 | Повторение переменных, циклов, условий, функций и списков |
| 8 | 22–24 | Накопление суммы, and, or |
| 9 | 25–27 | elif, break, continue |
| 10 | 28–30 | range с шагом, индексы, len и обход списка через while |
| 11 | 31–33 | Распаковка пар, логический return, параметры по умолчанию |
| 12 | 34–36 | Изменение списка, серпантин с вложенными циклами, итоговый квест |

Ориентир: 30–45 минут на занятие; подстраивайтесь под темп ученика. В начале попросите предсказать, куда пойдёт герой. После запуска обсудите разницу между прогнозом и результатом. Ошибка — повод прочитать журнал и изменить одну часть программы. В конце попросите объяснить решение своими словами и придумать его вариант.

Кнопка шестерёнки открывает раздел наставника со статистикой, возможностью открыть все уровни и экспортом прогресса. Эталонные решения доступны преподавателю в **solutions.py**. Не показывайте их до самостоятельной попытки. Проверка темы подтверждает наличие изучаемых конструкций в коде; понимание и осмысленность их использования лучше проверить устным объяснением.

## Сохранение

Решения, пройденные квесты и число попыток сохраняются автоматически в localStorage браузера для адреса игры. Используйте тот же браузер и адрес. Приватный режим или очистка данных могут удалить прогресс. В разделе наставника можно скачать JSON с прогрессом и текстами решений для архива; автоматического импорта в этой версии нет. Несколько учеников могут использовать отдельные профили браузера.

## Выполнение Python

Программы исполняются настоящим Python внутри браузера через Pyodide. Для уроков доступны команды героя, переменные, числа, строки, списки, условия, циклы, функции, return и простые встроенные функции: range, len, int, str, bool, abs, min, max, print. Импорты, файловые операции, доступ к внутренним объектам Python и внешние библиотеки не предоставляются. Ограничены время выполнения, размеры строк и списков, рост чисел и число игровых действий. Если программа перестаёт отвечать, браузер завершает отдельный Python Worker и создаёт новый.

Графика рисуется средствами браузера; внешних шрифтов, картинок, аналитики и CDN-зависимостей нет. Зафиксированная версия Pyodide хранится в папке `vendor`. Название, графика и сюжет самостоятельные; CodeCombat послужил ориентиром для механики обучения.

## Файлы сайта

- `index.html`, `style.css`, `app.js` — интерфейс, редактор и рисованная карта.
- `python-worker.js` — загрузка браузерного Python и обмен сообщениями с интерфейсом.
- `vendor/` — локальная браузерная среда Pyodide 314.0.7, включая Python и WebAssembly.
- `engine.py` — правила мира и безопасная проверка Python-кода ученика.
- `levels.py`, `chapter7.py` — тексты, карты и темы 36 квестов.
- `.nojekyll` — публикация файлов GitHub Pages без преобразования Jekyll.
- `.gitignore` — защита локальных тестов и эталонных решений от случайной публикации.

Локальные `server.py`, `solutions.py`, `chapter7_solutions.py` и тесты сохранены в папке, но исключены из Git.

## Новая глава: «За туманным перевалом»

Квесты 19–36 объединены в главу 7. Первые три закрепляют материал базовой кампании; следующие пятнадцать вводят более сложные приёмы и маршруты. Глава открывается после квеста 18. В разделе наставника можно открыть все уровни для выбора задания на занятии.

Существующие решения и пройденные уровни сохраняются для прежнего адреса: ключ хранения прогресса не менялся. Для переноса прогресса с локального адреса на GitHub Pages сначала скачайте его в разделе наставника старой версии, затем в новой версии нажмите «Загрузить сохранённый прогресс». Новые задания находятся в `chapter7.py`; все уровни загружаются браузерной Python-средой через `levels.py`.
